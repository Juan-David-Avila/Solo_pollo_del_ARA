### Objetivo del Reto
El desafío consiste en ejecutar este código:

```python
if __name__ == "__main__":
    print("Hola mundo")
```
Se probaron tres métodos distintos para ejecutarlo:
1) Bloc de notas
2) Python
3) Visual Studio Code (VS Code)
---
### Bloc de Notas
---
Este método aprovecha el editor de texto más básico. Así fue el proceso:
1. Abrí el Bloc de notas y pegue el Código extraído del Repositorio del reto #2 de GitHub
2. Guarde el archivo como avilaprimero.py
3. Abrí el explorador de archivos y entre en la ubicación específica del archivo
4. Ejecute el comando "Cmd" en la ruta del archivo para abrir la terminal directamente a partir de este
5. Cuando abri la terminal escribi "python avilaprimero.py"
6. Ejecutar(Enter)
### Así se muestra la ejecución del comando siguiendo los pasos anteriores

Python
---
Este método utiliza Python de manera directa, sin necesidad de editores de texto. Lo hice así:
1. Abrí directamente la terminal escribiendo "Win+R" y "Cmd"
2. Dentro de la terminal escribo el comando "Python" y lo ejecuto(Enter)
3. A continuación escribí el código propuesto del Repositorio del Reto #2
4. Ejecutar(Enter)
### De esta forma sencilla y fácil se observa ejecutado el famoso 'hola mundo'

Visual Studio Code
---
El enfoque más completo y estructurado para ejecutar el código fue con VS Code. De esta forma: 
1. Instalé VS Code: Descargue el editor desde Microsoft Store😑 y lo instalé
2. Preparé el entorno: En la sección de extensiones (Ctrl+Shift+X), busque e instale la extensión de Python
3. Luego abrí la carpeta con el código que había hecho en el bloc de notas "avilaprimero.py"(tambien se podia crear uno nuevo y pegar el código, igualmente válido)
4. Le di play y se ejecuto el comando del archivo en la terminal de VS Code
